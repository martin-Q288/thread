# 현월당 만세력 기준 v1.0

현월당의 만세력 계산에서 **공식 천문·달력 사실**과 **명리 해석 규칙**을 분리한다.

## 1. 공식 기준층

다음 항목은 한국천문연구원(KASI) 공개 자료를 최우선 기준으로 둔다.

- 양력 ↔ 음력 변환
- 윤달 여부와 음력 월의 대소
- 24절기의 날짜와 한국표준시(KST) 기준 절입 시각
- 일진(60갑자) 검증용 기준값

공식 기준 출처:

- 한국천문연구원 천문우주지식정보 달력자료(월력요항): https://astro.kasi.re.kr/life/post/calendardata
- 한국천문연구원 월력요항 발표 자료: https://www.kasi.re.kr/kor/post/newsMaterial/32031

월력요항은 천문역법에 따른 달력 제작의 기준 자료로 사용한다.

## 2. 계산 구현층

현재 계산 라이브러리는 `manseryeok@2.0.0`을 사용한다. 이 라이브러리는 자체 문서상 KASI 정본 음력 데이터와 KASI와 분 단위로 일치하는 절기표를 기반으로 한다고 밝히고 있다.

다만 **라이브러리의 주장 자체를 공식성의 근거로 사용하지 않는다.** 현월당은 별도 QA에서 KASI 공식 월력요항의 공개값과 직접 교차검증한다.

현재 QA 기준:

- 2026년 24절기 24건
- 2027년 24절기 24건
- 2026년 음력 각 월 1일의 양력 대응 12건
- 2027년 음력 각 월 1일의 양력 대응 12건
- 위 24개 날짜의 일진 24건

합계 96개 공식 앵커를 자동 비교한다.

이 검증은 현재 계산 라이브러리의 **스모크/회귀 검증**이며, 1800~2100 전 구간을 공식 원자료와 전수 대조했다는 뜻은 아니다. 전 구간 검증은 별도 데이터셋으로 확대한다.

## 3. 현월당 명리 규칙

아래는 KASI가 정하는 내용이 아니라 현월당이 고정해서 사용하는 명리 계산 규칙이다.

- 연주 경계: 입춘 절입 순간
- 월주 경계: 12절(節) 절입 순간
- 일 경계: 자정 00:00 (`dayBoundary = midnight`)
- 입력 시각: 사용자가 알고 있는 출생 당시의 민간/공적 기록 시각을 우선 사용
- 진태양시/경도·균시차 보정: 기본 적용하지 않음
- 출생시간 미상: 임의의 시주를 사용자에게 제시하지 않으며 시주 기반 판단을 제외
- 대운: 성별과 연간 음양에 따른 순·역행 및 절입까지의 거리 계산을 사용하되, 시작 나이는 학파 차이가 있을 수 있으므로 내부 검증 대상에 포함

`진태양시`, `야자시/조자시`, 대운 시작 시점 등 학파별로 결과가 갈릴 수 있는 항목을 KASI의 공식 천문 사실처럼 표현하지 않는다.

## 4. 공개 전 통과 조건

1. KASI QA 96/96 통과
2. 입춘 전후 1분 경계 테스트 통과
3. 각 월 절입 전후 1분 경계 테스트 통과
4. 양력/음력 왕복 변환 테스트 통과
5. 윤달 사례 테스트 통과
6. 23:00~00:30 일 경계 사례 테스트 통과
7. 출생시간 미상에서 시주가 해석에 섞이지 않는지 확인
8. 같은 입력은 항상 같은 명식을 반환

검증 실패 시 사용자에게 유료 풀이를 제공하기 전에 계산 계층부터 수정한다.
